PASOS PARA PUBLICAR
  1. Repositorio mylife-app (Public) -> "uploading an existing file" -> arrastra los
     archivos -> Commit changes (Commit directly to the main branch).
  2. Settings -> Pages -> Deploy from a branch -> main, "/ (root)" -> Save.
  3. Custom domain: app.proyectopasivo.com -> Save.
  4. En el DNS de proyectopasivo.com: registro CNAME, nombre "app",
     apunta a proyectopasivo2026.github.io
  5. Cuando GitHub verifique el DNS, marcar "Enforce HTTPS".
  6. En el celular: abrir https://app.proyectopasivo.com en Chrome, con internet ->
     menu (3 puntos) -> "Instalar app". Iniciar sesion con Google.
  7. Probar sin internet: cerrar la app, modo avion, abrirla desde el icono.
